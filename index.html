The AI talks to customers. The code decides what gets booked.

An AI receptionist books, moves and cancels appointments through this server. It can be talked into anything, so none of the rules live in its prompt. Run a scenario, or open the tool console and try to break them yourself.

  • No double bookings, no booking outside opening hoursslot_taken · closed
  • Customer must confirm a preview before anything is bookedpreview
  • Only the phone that made a booking can see or change itnot_found
  • Changes inside 24 hours go to a person, not the AIneeds_approval
  • Every call is logged in a chain that shows any editsha-256
